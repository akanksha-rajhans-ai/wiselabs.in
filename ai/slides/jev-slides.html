01 · The Problem

Agent Loops Are Slow and Expensive

LLM decides
→
Tool executes
→
LLM evaluates
→
repeat…
  • Tool calling + structured outputs made LLMs wireable into software
  • But every decision in the loop still costs a full model call
  • Most of those decisions aren't generation tasks — they're classification tasks wearing a chat-completion costume
02 · The Answer

Enter Jev — A "System One" Model

  • No text generation — ever
  • Input: a state (context) + typed questions
  • Output: typed, calibrated probabilities your code branches on directly
  • Trained with Reinforcement Learning for Calibrated Decisions (RLCD)
  • Built by Diogo Almeida (ex-OpenAI, RLHF co-inventor) at TypeSafe AI

    "is_urgent": { "type": "noul" }
  }
}
// → { "is_urgent": 0.999 }
03 · The Primitives

Three Typed Questions, Nothing Else

  • Noul — yes/no → probability the statement is true
  • Choice — pick one option → per-option probability + confidence
  • Score — rate against ordered levels → continuous score + distribution
Every real use case is built from these three. You can ask several in one request — evaluated in parallel, near-zero extra latency.
04 · Deep Dive

Where Jev Fits in Today's Agentic Loop

  • Model routing — Jev classifies request difficulty; cheap model for lookups, powerful model for hard reasoning
  • Tool-call guardrails ("Auto Mode") — screens a risky action before it executes; block, allow, or hold for review
  • Harness-level triage — the same "is this dangerous?" check that's long lived inside closed-source coding harnesses is now buildable into any agent
  • Pre/post steps — classify intent before generation, review an agent's finished run before accepting it

05 · Deep Dive, cont.

Why the Price Actually Changes Behavior

  • 1,000,000 calls × ~1,000 input tokens each ≈ $42 before infra
  • Cheap enough to check every request, not just the expensive ones
  • Cheap enough to review every agent action before it's accepted
  • This is the Jevons paradox bet baked into the name — cheaper decisions → far more decisions get made, not fewer
Caveat: these are vendor-published launch numbers, not independent benchmarks. Validate speed, cost, and calibration on your own workload before trusting the thresholds.

07 · Reality Check

What to Watch Before You Ship It

  • Early access — API, pricing, and model versions are still moving
  • No explanation trace — you get a number, not a reason
  • Ecosystem is days old: official Python/JS SDKs, community jev-cli, LangChain, OpenRouter, Vercel AI Gateway
  • TypeSafe's own guidance: calibrate on your data, keep human fallback on high-impact actions
Takeaway

One Line to Remember

Jev doesn't replace your LLM — it replaces the hundreds of cheap yes/no decisions your agent was quietly paying full LLM price for.
